# Observability

## Objective
Monitor workflow execution and identify issues affecting retrieval and answer quality.

## Key Signals
- Workflow execution success and failure rates.
- Document ingestion and indexing status.
- Query latency and response failures.
- Retrieval relevance and answer correctness.
- Abstention frequency.

## Monitoring Approach
- Review n8n execution logs.
- Track ingestion and query failures.
- Evaluate answer quality using the test dataset.
- Investigate recurring failures and prioritize corrective actions.
